# Worship At The Shop

The weekly page for Thursday nights at the Shop.

- `weeks.js` — the schedule and each week's passage, song, focus and menu. The page shows the next Thursday automatically.
- `config.js` — the Google Apps Script web app that saves RSVPs, votes, prayers and questions to the "Worship At The Shop — Responses" Google Sheet.
- `apps-script/Code.gs` — a copy of that backend script.
- Preview a future week with `?date=YYYY-MM-DD`.
